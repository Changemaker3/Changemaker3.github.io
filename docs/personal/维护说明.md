# 网站维护说明

网站名称是 JinghaoJin，默认英文，右上角可切换中文。中文和英文各有独立网址，在对应栏目之间切换。深色模式沿用 al-folio 的设置。

## 更新个人资料

修改 `_data/profile.yml`。`en` 中是英文简介和研究方向，`zh` 中是中文版。邮箱和社交链接由两个版本共用。这里的 GitHub 信息应当是主页链接，而不是注册邮箱。

如需头像，把真实照片放在 `assets/img/`，将 `photo` 填为 `/assets/img/文件名.jpg`。如需简历，把 PDF 放在 `assets/pdf/`，填写 `cv`。空值会自动隐藏对应入口。

## 添加论文

把 BibTeX 添加至 `_bibliography/papers.bib`。论文保持原始标题、作者顺序和发表状态。`arxiv`、`pdf`、`html`、`code` 字段控制链接；只有提供的链接才会显示。`selected = {true}` 的论文也会显示在首页。没有 `journal` 的条目会显示为预印本；日后如添加会议论文，可按真实类型扩展这个标签。

当前论文元数据来自 INSPIRE 记录 3159215，并与 arXiv:2605.24978 核对。arXiv 首次公开日期为 2026-05-24。Springer 与 Crossref 确认已于 2026-09-09 正式发表于 JHEP，2026 年第 9 期，第 123 号文章，DOI 为 10.1007/JHEP09(2026)123。网站采用最新出版社信息；INSPIRE 当时尚未同步期刊信息。

## 添加笔记与报告

1. 从 `templates/` 复制对应的 `.md.example` 文件到 `_notes/` 或 `_talks/`。
2. 把扩展名改为 `.md`，替换标题、日期、摘要和正文。
3. 为同一篇内容准备英文和中文两个文件。`lang` 分别填写 `en` 和 `zh`。
4. `permalink` 填当前页网址，`alternate_url` 填对应语言的网址。两者应互相对应。
5. 报告可附 `slides` 和 `video` 链接。幻灯片文件可以放在 `assets/pdf/`。

正文支持 Markdown、LaTeX 公式与代码块。示例仅存放在不公开的模板目录里，不会成为你的个人成果。

## 预览与发布

运行 `npm run dev` 后访问终端显示的地址。更新 `_config.yml` 后需重启预览服务。运行 `npm run build` 生成 `dist/`，`npm run check:site` 检查语言跳转、页面、论文与本地资源链接。

目前通过 Sites 发布。发布地址改变时，更新 `_config.yml` 的 `url`；部署到 GitHub 项目子目录时，还需设置正确的 `baseurl`。网站也可以迁移到支持静态 HTML 的其他托管服务。

如需让别人通过 Google 搜索姓名找到网站，继续阅读 [Google 收录说明](Google收录.md)，在自己的账号下验证网站并提交站点地图。
